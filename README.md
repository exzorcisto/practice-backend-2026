# Survey API — Сервис опросов и голосований

**Survey API** — это backend-платформа, позволяющая создавать анкеты с различными типами вопросов, собирать ответы и анализировать результаты. Проект разработан на базе Laravel с акцентом на гибкую архитектуру данных.

---

## 🛠 Технологический стек

* **Framework:** Laravel 12.0 (PHP 8.4)
* **Database:** MySQL 8.0
* **Auth:** Laravel Sanctum (Token-based)
* **API Testing:** Thunder Client

---

## 📊 Проектирование базы данных (ER-диаграмма)

База данных спроектирована с учетом поддержки различных типов вопросов (одиночный выбор, текст) и контроля уникальности ответов респондентов.

### Основные сущности:
* **role**: Справочник ролей пользователей (Author, Listener).
* **users**: Учетные записи с разграничением прав доступа.
* **surveys**: Заголовки и метаданные опросов.
* **questions**: Вопросы, привязанные к опросам, с указанием типа (radio, text и др.).
* **question_options**: Варианты ответов для вопросов с выбором.
* **survey_responses**: Регистрация факта прохождения опроса пользователем.
* **answers**: Детальные ответы на конкретные вопросы.

---

## 📡 Проектирование API эндпоинтов

Ниже представлен список запланированных эндпоинтов для реализации функционала:

### Аутентификация
* `POST /api/register` — Регистрация нового пользователя.
* `POST /api/login` — Авторизация и выдача API-токена.

### Опросы (Автор)
* `POST /api/surveys` — Создание нового опроса (черновик).
* `GET /api/surveys` — Получение списка всех опросов автора.
* `GET /api/surveys/{id}` — Детальная информация об опросе.
* `PATCH /api/surveys/{id}` — Редактирование структуры (доступно только для черновиков).

### Голосование (Слушатель)
* `GET /api/surveys/active` — Просмотр списка опубликованных опросов.
* `POST /api/surveys/{id}/responses` — Отправка ответов на вопросы.

## 🚀 Начало работы

1. **Клонирование проекта:**
   ```Terminal
   git clone [https://github.com/exzorcisto/survey-api.git](https://github.com/exzorcisto/survey-api.git)
   cd survey-api
   ```
2. **Настройка окружения:**
   cp .env.example .env
   ```.env
   DB_CONNECTION=mysql
   DB_HOST=MySQL-8.0
   DB_PORT=3306
   DB_DATABASE=survey_db
   DB_USERNAME=root
   DB_PASSWORD=
   ```
3. **Установка и миграции:**
   ```env
   composer install
   php artisan key:generate
   php artisan migrate --seed
   ```
